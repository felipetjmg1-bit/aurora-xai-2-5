# AURORA XAI 2.5 · fluxo passo a passo

Interface de IA explicável para explorar entradas e resultados.

## 1. INICIAR A INTERFACE

Abrir a aplicação web e carregar a experiência disponível.

## 2. CONFIGURAR ENTRADA

Selecionar dados e parâmetros aceitos pela interface.

## 3. EXECUTAR FLUXO

Acionar a função de análise implementada no projeto.

## 4. INSPECIONAR EXPLICAÇÃO

Ler os elementos explicativos e informações apresentadas.

## 5. AVALIAR LIMITAÇÕES

Conferir origem dos dados e o que ainda não foi validado.

## Resultado e limites

Interface em evolução. Explicações visuais não equivalem automaticamente a explicabilidade validada do modelo.
